# Bulk Engine

Bulk Engine は、Annotation 後の database からラベル別の細胞集団を選び、長さ、面積、蛍光局在、強度分布などをまとめて解析する画面です。

![Bulk engine selection](/img/screenshots/bulk1.png)

![Bulk engine analysis](/img/screenshots/bulk2.png)

## 使い方

1. database を指定して Bulk Engine を開く。
2. preview channel と label を選び、解析対象の細胞集団を確認する。
3. `Analysis mode` で指標を選ぶ。
4. `Phenotype map`, `Cell length`, `Cell width`, `Cell area`, `Normalized median`, `FITC aggregation ratio`, `Entropy`, `Heatmap`, `Contours`, `Map256`, `Raw data` を実行する。
5. plot を確認し、必要に応じて JSON/CSV を export する。

![Bulk engine heatmap](/img/screenshots/bulk4.png)

## 主要な解析

### Phenotype map

`Phenotype map` は 1 点を 1 細胞として、形状と蛍光指標を探索する散布図です。
X/Y 軸には細胞長（px）、平均・中央全幅（px）、面積（px²）、選択チャンネルの
normalized median を指定できます。色は manual label または数値指標で切り替えます。
FLUO1/FLUO2 の値はまとめて取得するため、軸やチャンネルの変更では再計算しません。

1. 点をクリックして細胞を選ぶ。Shift-click で選択を追加・解除する。
2. プロットの空白からドラッグして、矩形内の細胞を選ぶ。
3. `Cell details` で PH/蛍光画像と値を確認し、`Open Cell Viewer` で元の細胞を開く。
4. `Zoom to selection` で選択集団を拡大し、`Reset view` で全体へ戻る。
5. `Export selected CSV` で選択細胞の全指標を、`Export selection JSON` で指標と表示条件を保存する。

選択は軸を切り替えても細胞 ID に対応します。manual label の絞り込みを変えると
選択は解除されます。`Select all visible` は現在の表示範囲内の点を選びます。
元画像は選択した細胞から読み込み、一覧は 24 細胞ずつ表示します。

欠損を 0 に置き換えず、軸の値がない細胞は欠損件数として表示します。
CSV では空欄、JSON では `null` です。全画素が 0 の蛍光画像の normalized median は 0 です。
輪郭・画像の編集後は `Refresh measurements` で再取得できます。
JSON には DB 名、元データの識別値、指標の単位・バージョン、中心線次数、
選択細胞と軸・色・チャンネル・絞り込み・表示範囲を記録します。

直接開く場合は `/bulk-engine?dbname=sample.db&mode=phenotype-map` を使えます。

### 個別の指標

`Cell length` は、輪郭内部ピクセルを PCA 主軸へ射影し、最大射影値と最小射影値の差を px 単位で返します。

$$
L_{\mathrm{px}} \approx \max_i \pi_i - \min_i \pi_i
$$

`Cell area` は抽出時に保存された輪郭面積を px² 単位で返します。

`Cell width` は、細胞中心線の多項式に対する各輪郭座標の最短距離を求め、距離の平均値と中央値をそれぞれ 2 倍して全幅の推定値（px）として返します。

`Normalized median` は輪郭内の強度値を細胞ごとの最大値で割り、中央値を取ります。

$$
m(C) = \mathrm{median}\left(\frac{I_i}{\max I}\right)
$$

`FITC aggregation ratio` は normalized median が既定しきい値 `0.7414` 未満の細胞割合を計算します。

$$
R = \frac{1}{N}\sum_{c=1}^{N}\mathbf{1}[m(C_c) < 0.7414]
$$

`Heatmap` は細胞中心線に沿って蛍光ピークベクトルを作り、絶対長または相対位置で並べます。`Contours` は PCA で細胞の向きを揃えた輪郭座標を描画・export します。
